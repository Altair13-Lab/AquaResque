# CRS-10 · Caspian Rescue Systems

Адаптивный демонстрационный интерфейс ситуационного центра спасательных дронов на React, TypeScript, Vite и Tailwind CSS.

## Запуск в VS Code

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте показанный Vite адрес (обычно `http://localhost:5173`). Для проверки production-сборки выполните `npm run build`, затем `npm run preview`.

## Деплой на Vercel

1. Создайте репозиторий проекта на GitHub и отправьте в него исходные файлы (папки `node_modules` и `dist` игнорируются Git).
2. Войдите в [Vercel](https://vercel.com/), выберите **Add New → Project** и импортируйте GitHub-репозиторий.
3. Оставьте настройки Vite по умолчанию: install `npm install`, build `npm run build`, output directory `dist`. Они также заданы в `vercel.json`.
4. Нажмите **Deploy**. Публичный URL появится на странице проекта; последующие push в подключённую ветку будут запускать новый деплой.

Vercel-конфигурация находится в `vercel.json`. `index.html` использует `/src/main.tsx`, который Vite компилирует во время сборки.

## Возможности макета

- Переключение ролей «Акимат», «ЧС Оператор» и «Частный клиент».
- USB-видеокамера через `getUserMedia`, выбор камеры и отключение видеопотока.
- Обнаружение класса «человек» на живом видеопотоке с помощью COCO-SSD / MobileNetV2 в браузере: рамка вокруг цели, confidence score и положение X/Y в процентах кадра.
- Переключаемые RGB, Thermal Heatmap и Night Vision IR режимы. Последние два — CSS-фильтры обычной камеры, не данные физического тепловизора или ИК-сенсора.
- Ориентировочная метка сноса баллона, явно обозначенная как учебная оценка, а не физически откалиброванный прогноз.
- Панель `ControlPanel.tsx`: подтверждаемый Web Serial сброс и локальное AES-GCM шифрование демонстрационного пакета ДЧС. Пакет никуда не отправляется; реальной интеграции с 112 нет.
- Карта ежедневных статусов пляжных секторов с выбором даты и локальным сохранением статусов. Для текущей даты есть только учебные примеры; схема не является точной картой пляжей или официальным предупреждением.
- Сводка акимата включает демонстрационный рой из трёх бортов; время реакции показано как проектная цель, а не достигнутый результат. Данные о спасённых жизнях и индекс пляжной безопасности не подменяются вымышленными цифрами.
- Анимированный многослойный фон, контурная графика побережья и плавные состояния кнопок с поддержкой `prefers-reduced-motion`.
- Ситуационная панель побережья, телеметрия, журнал событий и макет архитектуры микросервисов.
- Web Serial API для подключения совместимого контроллера и отправки команды `CRS10:PAYLOAD_RELEASE\n` после явного подтверждения оператором.
- Демо-режим сброса и SOS не управляют оборудованием и не отправляют реальные обращения.

Камера и Web Serial требуют поддерживаемый браузер и защищённый контекст (`localhost` или HTTPS). Web Serial доступен, например, в Chrome и Edge. Веса COCO-SSD загружаются из TensorFlow Hub в браузер при первом запуске AI, поэтому нужен интернет. Перед подключением исполнительного устройства согласуйте формат команды, протокол подтверждения и аппаратную блокировку с прошивкой контроллера.

Модель находит объекты класса «человек» в кадре, но не распознаёт утопление, не анализирует поведение или волны и не определяет GPS-координаты человека. X/Y — относительное положение в изображении. Карта статусов позволяет вносить ручные отметки по датам в локальное хранилище браузера; официальные сводки ДЧС, спасателей и метеослужбы не подключены. Схема береговых зон и состояния флота демонстрационные. Это не сертифицированное средство безопасности. RTSP/WebRTC, WebSocket, интеграция с 112/ДЧС и спутниковая связь показаны как целевая архитектура и не реализованы. Интерфейс не заменяет службу спасения. При реальной чрезвычайной ситуации звоните 112.
